# 지뢰찾기

Python 기반 지뢰찾기 게임입니다.

## 특징

- **힌트 시스템**: 게임 당 5개의 힌트가 주어지며, `H` 키를 눌러 힌트 모드를 활성화한 뒤 안전한 셀을 열거나 지뢰를 확인할 수 있습니다
- **틀린 플래그 표시**: 게임 오버 후 틀리게 표시한 플래그는 노란색 X로 표시되어 실수를 명확히 볼 수 있습니다

## 게임 조작법

| 입력 | 동작 |
|------|------|
| **왼쪽 클릭** | 셀 열기 |
| **오른쪽 클릭** | 셀에 플래그 토글 |
| **중간 버튼** | 인접한 열리지 않은 셀 하이라이트 (600ms 지속) |
| **H 키** | 힌트 모드 활성화 (클릭할 때마다 힌트 1개 소비) |
| **R 키** | 게임 재시작 |

## 시작하기

### 필수 요구사항

- Python 3.7 이상
- Pygame

### 설치

1. 저장소 클론
2. 의존성 설치:

```bash
pip install pygame
```

### 게임 실행

```bash
python run.py
```

16×16 보드와 40개의 지뢰를 가진 게임 윈도우가 열립니다.

## 프로젝트 구조

```
.
├── run.py          # 게임 루프, 렌더링, 입력 처리
├── components.py   # 핵심 게임 로직 (Board, Cell, CellState)
├── config.py       # 게임 설정 (보드 크기, 색상, 폰트)
└── readme.md       # 이 파일
```

### 모듈 설명

- **run.py**: UI를 그리는 `Renderer`, 사용자 입력을 처리하는 `InputController`, 게임 루프를 조율하는 `Game` 클래스를 포함합니다
- **components.py**: 그리드 관리와 지뢰 배치, 셀 열기 및 플래그 토글 로직을 담당하는 `Board`, 개별 셀을 나타내는 `Cell`, 셀 상태를 추적하는 `CellState` 클래스를 포함합니다
- **config.py**: 보드 크기, 색상, 폰트, 입력 설정 등 모든 게임 설정을 중앙에서 관리합니다

## 게임 플레이 방법

1. **게임 시작**: `python run.py`로 게임을 실행합니다
2. **첫 클릭**: 아무 셀이나 클릭하면 됩니다. 그 위치에는 절대 지뢰가 나타나지 않습니다
3. **셀 열기**: 셀을 클릭하여 열어봅니다. 인접 지뢰가 0개인 셀의 경우, 주변 셀들이 자동으로 연쇄 오픈됩니다
4. **플래그 표시**: 의심되는 지뢰 위치에 오른쪽 클릭으로 플래그를 표시합니다
5. **힌트 사용**: `H` 키를 눌러 힌트 모드를 활성화한 후 셀을 클릭하면 안전하게 셀을 열거나 지뢰를 확인할 수 있습니다 (게임 당 5개 힌트)
6. **승리**: 모든 지뢰가 아닌 셀을 열면 게임을 이깁니다
7. **재시작**: `R` 키를 눌러 새 게임을 시작합니다

## 기술 세부사항

- **지뢰 배치**: 첫 클릭 위치와 그 주변 8개 셀을 포함한 안전 영역을 확보한 후 무작위로 지뢰를 배치합니다
- **플러드 필**: 인접 지뢰가 0개인 열리지 않은 셀들이 자동으로 연쇄 오픈되어 사용자 경험을 개선합니다
- **인접 셀 추적**: 중간 버튼 클릭으로 주변의 열리지 않은 셀들을 600ms 동안 강조 표시하여 전략적 게임 플레이를 돕습니다
- **게임 상태 관리**: 게임 시작 여부, 경과 시간, 플래그 표시 상태, 승패 조건 등을 추적합니다
